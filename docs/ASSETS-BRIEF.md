# ТЗ на графику для GPT (Ассет)

Общий стиль для всех промптов — добавляйте в начало:

> Современный премиальный стиль в духе macOS / iOS: плоская форма-«сквиркл» со сглаженными углами, мягкий внутренний блик сверху, тонкая светлая внутренняя обводка, аккуратная мягкая тень. Один главный символ по центру, без текста, без мелких деталей. Чистая геометрия. Фон — прозрачный (PNG с альфа-каналом).

## Палитра
| Токен | HEX | Роль |
|---|---|---|
| Volt | `#FFD60A` (градиент `#FFEC6B → #E8B900`) | фирменный жёлтый |
| Graphite | `#0C0C0F` / `#17171C` | чернила, тёмные поверхности |
| Plasma | `#6A5CFF` (градиент `#A89CFF → #5446E6`) | второй акцент |
| Белый | `#FFFFFF` | блики, символ на цветном фоне |

## 1. Логотип (молния)
Файлы: `public/brand/logo-mark.svg` (векторный) и `public/brand/logo-mark.png` (1024×1024).
- Знак: стилизованная молния, слегка наклонённая, острые, но чуть скруглённые углы; читается при 16 px.
- Версия A (основная): graphite-молния `#0C0C0F` на сквиркле Volt `#FFD60A`.
- Версия B: Volt-молния на graphite-сквиркле.
- Версия C: одноцветная (для печати/штампа), без градиентов.
- Горизонтальный логотип: знак + слово «Ассет» (жирный гротеск с кириллицей, близкий к SF Pro / Inter Bold, плотный трекинг) — `public/brand/logo-horizontal.svg`.
- Охранное поле — высота молнии/4 со всех сторон.

> Для GPT: просите **вектор/SVG**. Если выдаст растр — прогоните через векторизатор.

## 2. Иконки услуг (3 шт., 1024×1024 PNG, прозрачный фон)
Формат — «иконка приложения» (сквиркл 22.37%), как на iOS/macOS.

| Файл | Символ | Цвет фона |
|---|---|---|
| `public/brand/icon-social.png` | диалоговое облачко + маленькая молния/сердечко внутри | градиент Volt |
| `public/brand/icon-web.png` | окно браузера с тремя точками и курсором/галочкой | градиент Plasma |
| `public/brand/icon-automation.png` | два связанных узла-блока с линией потока, один «искрит» молнией | градиент Graphite `#52525C → #17171C`, символ — белый + Volt-акцент |

## 4. Иллюстрации (по желанию, позже для портфолио)
Формат 4:3, WebP/PNG ≥ 1600 px, мягкие градиентные сцены в палитре выше, без текста.

## Как подключить
- **Иконки услуг:** в `src/components/Services.tsx` замените `<ServiceIcon name={s.icon} />` на  
  `<img src={`/brand/icon-${s.icon}.png`} alt="" width="64" height="64" />`  
  (стиль `.app-icon img` уже готов; фон-подложку у `.app-icon` можно убрать, если PNG уже со сквирклом).
- **Логотип:** в `src/components/Logo.tsx` замените `<IconBolt />` на `<img src="/brand/logo-mark.svg" alt="" />`.
